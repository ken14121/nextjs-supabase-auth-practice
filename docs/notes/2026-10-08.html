朝のつまずき

起きたこと原因対処
Module not found（d3-geo・@typesafe-ai/sdk）家の PC で、増えたパッケージをまだ入れていなかったyarn dev を止めて yarn install
「JEV_API_KEY が設定されていません」キーをコクーンの PC にしか入れていなかった家の PC の .env.local に JEV_API_KEY=… を書き、yarn dev を起動し直す

.env.example は GitHub に上がる見本、.env.local は上がらない本物。キーは必ず .env.local に書く。コミットする前に git status を見るくせをつけると、こういうミスに気づける。

02

取り込み直しで同じ外出が 2 件になる

タイムラインを書き出し直して取り込むと、外出が 447 件に増えていた。Google は書き出すたびに区切りを少し変えることがあり、開始時刻が数分ずれる。前は「開始時刻がまったく同じなら同じ外出」と見ていたので、ずれた分が別の外出として増えていた。

新しいファイルの外出取り込み直したもの → 時間が重なる DB の行を探すlib/timeline/match.ts → あれば上書き判定・メモを引き継ぐ → どれとも重ならない古い行は消すファイルの期間内だけ

候補が 2 つあるときは、自分で判定を決めた行を優先し、次に重なりが長い行を選ぶ。取り込み直したあとは 386 件で、重複はなくなった。

05

自分の基準を言葉にする

外れたものを見ながら、自分ならどう決めるかを言葉にした。

  • 「家のそばすぎる移動の時は、バイトとかの可能性があるから日常」
  • 「都内でも新宿が学校だから、そこ以外は基本おでかけかも」
  • 「でも学校のあとに友人と新宿で遊ぶときもある」

3 つ目が大事。「新宿なら日常」とは決められない。そこで場所の名前ではなく、いつもの場所以外でどれだけ過ごしたかで決めることにした。

直したところ中身
ルール（Jev を使わない）泊まっていない日で、自宅から一番遠い地点が 5 km 以内なら日常（NEAR_HOME_KM）
Jev の質問「日常ですか」いつもの場所だけの日は日常／自宅の近くだけなら日常／いつもの場所以外で 1 時間以上過ごした日は、学校の前後でも日常ではない／旅行・帰省・遠出は日常ではない
聞き直すボタン自分が確かめた外出は、自分の答えはそのままにして Jev の答えだけ取り直す。まだ確かめていない Jev の判定は未判定に戻す

同じ 57 件で、直す前と後の正解率を比べられる。別の外出で比べると「たまたま簡単な外出だった」かもしれないが、同じ外出なら質問を変えた効果だけが分かる。

基準を言葉にするのは面倒だが、Jev は「その人にとっての日常」を知らないので、ここを伝えるのがいちばん効く。直す前の結果は docs/JEV.md に残した。

06

確かめやすくする

ランダムに並んでいると、日付が飛び飛びで思い出しにくい。選ぶのはランダム、見せる順番は古い順に分けた。

  • 選び方はランダムのまま：「要確認」だけや新しいものだけを見ると、正解率が偏ってしまうため
  • 外出 ID から決まるランダム（stableRandom）なので、ページを開き直しても一覧が入れ替わらない
  • 各行に、出発〜帰宅の時刻・いつもの場所にいた時間・ふだん行かない場所にいた時間・自宅から最大何 km を出して、思い出す手がかりにした
07

理解度チェック

  1. 取り込み直すと同じ外出が 2 件になったのはなぜ？どう直した？

    答えを見る

    Google が書き出すたびに開始時刻が数分ずれることがあり、「開始時刻がまったく同じ」でしか同じ外出と見ていなかったから。「時間が重なっていれば同じ外出」とみなして、DB の行を引き継ぐようにした。

  2. 「要確認あり」の正解率が「なし」より低いのは、良いこと？悪いこと？

    答えを見る

    良いこと。要確認の目印が、外れやすい外出をちゃんと見分けられているということ。要確認のものだけ見れば効率よく直せる。

  3. 確率の当てはまりの表で、「平均」と「実際の割合」が近かった。何が分かる？

    答えを見る

    Jev の言う確率はだいたい信じられる。外れの原因は確率の出し方ではなく、何を日常と呼ぶかという基準を Jev が知らないことにある。

  4. 「新宿なら日常」というルールにしなかったのはなぜ？

    答えを見る

    学校のあとに新宿で友人と遊ぶ日もあるから。場所の名前ではなく、いつもの場所以外で 1 時間以上過ごしたかどうかで決めるようにした。

  5. 質問を変えた効果を、同じ 57 件で比べるのはなぜ？

    答えを見る

    別の外出で比べると、たまたま簡単な外出が多かっただけかもしれない。同じ外出で比べれば、違いは質問を変えたことだけになる。
