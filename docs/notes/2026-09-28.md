### Supabase で選んだ設定の意味

| 設定 | 選択 | 意味 |
| --- | --- | --- |
| Data API | ON | テーブルを URL 経由で読み書きできる入口。supabase-js はここを使う |
| 新しいテーブルを自動で公開 | OFF | テーブルを作っても勝手に外から触れない。使うテーブルごとに権限（`grant`）を付ける |
| 自動 RLS | ON | 新しいテーブルに「行ごとの鍵」が最初からかかる。「自分のデータだけ見える」ルールを書く前提 |

### 明日以降の「Google ログイン」のしくみ（予習）

```
① ユーザーがアプリの「Google でログイン」を押す
② Supabase Auth が Google のログイン画面へ案内する
③ Google「このアプリにログインしていい？」→ ユーザーが許可
④ Google → Supabase に「この人は本人です」と返す（ここで Google Cloud の OAuth クライアント ID を使う）
⑤ Supabase → アプリにログイン済みの情報（Cookie）を渡す
⑥ Next.js の proxy.ts が毎回 Cookie を確認し、ログイン状態を保つ
```

Google Cloud は「このアプリが Google ログインを使ってよい」という許可証を出す役、Supabase はログインした人を覚えておく役。

### Jev のしくみ（予習）

- 入力: **State**（判断材料の文章）＋ **Questions**（何を判断させるか）
- 質問の型は 3 つ: **Choice**（選択肢から 1 つ）/ **Score**（点数）/ **Noul**（正しい確率）
- 出力: 選んだ答えと確率。文章は書かない
- 料金は入力だけにかかり、出力は無料。計算や日付の比較は苦手なので、距離や泊数はこちらで計算して渡す
- 現在: TypeSafe が 9/22 から新規登録を一時停止しており、新しいアカウントに無料クレジットが付かない → Zendash 側で対応待ち

## 5. 今日触ったしくみ

- **`yarn dev`**: 開発用サーバーを起動し、`http://localhost:3000` でアプリを見られるようにする。`localhost` は「自分の PC」のこと
- **ホットリロード**: ファイルを保存すると、リロードしなくても画面が更新される
- **JSX / TSX**: JavaScript（TypeScript）の中に HTML のような書き方ができる形式。ソースで文章を改行すると、表示ではスペースになる
- **Tailwind CSS**: `className="text-3xl text-blue-600"` のように、クラス名を並べて見た目を指定する
- **`lang="ja"`**: ページの言語をブラウザに伝える。`jp` は国のコード、`ja` が言語のコード
- **Biome**: `yarn lint` で書き方のミスを見つけ、`yarn format` で字下げなどを自動で整える
- **Git の流れ**: 変更 → `git add`（記録する変更を選ぶ）→ `git commit`（記録する）→ `git push`（GitHub に送る）
- **ブランチ**: 今の作業は `claude/dreamy-euler-flpzg9` ブランチにあり、`main` にはまだ入っていない

## 6. つまずいたことと学び

| 起きたこと | 原因 | 対処 |
| --- | --- | --- |
| Jev が使えない（Billing error） | TypeSafe が 9/22 から新規登録を一時停止し、無料クレジットが付かない | Slack で Zendash に相談 → 対応してもらうことに |
| Linter が ESLint で作られた | コマンドにオプションを 1 つでも付けると、残りは質問せずデフォルトで作られる | 全部の設定をオプションで指定して作り直した |
| 作り直しで `next-env.d.ts` が衝突 | `.gitignore` 対象のファイルは `git clean` で消えない | 手で削除 |
| Biome 2.2 が入った | 作成ツールの初期設定が古い | `yarn add -D -E @biomejs/biome@2.4` → `biome migrate` |
| `yarn lint` で Tailwind の書き方がエラー | Biome 2.4 は Tailwind の構文が初期状態で無効 | `biome.json` に `css.parser.tailwindDirectives: true` |
| React が 19.2.4 | 作成ツールの初期値 | `yarn add -E react@19.2.5 react-dom@19.2.5` |
| 日本語が単語の途中で折り返す | 日本語はスペースがないので、どこでも折り返される | `<br />` や `[word-break:auto-phrase]` |
| `lang="jp"` でエラー | 言語コードは `ja` | `lang="ja"` に修正 |
