# Syllabuzz の本番サイトを使ってみた気づき（10/26〜10/30、10/30(金) 提出）

ゆうへいさんからの依頼（10/23 Slack）：
- 学校のメールアドレス（tks.put.ac.jp）でサインアップして、実際のサイトで色々とやってみる
- 先週と同じように、金曜にレポートを出す
- コースのおすすめは、IPUT のコースが登録されていないので使えない（エラーとして書かない。ただし「使えないと分かるか」は見る）
- 来週のどこかで、社長がデモと LP を触った段階でのインタビューをしたい（連絡が来る）

> 先週と同じく、触りながらその場でメモする（あとから思い出すと「慣れた人の目」になってしまう）。
> 本番のアカウントなので、スクリーンショットは名前・メールアドレス・学籍番号などを隠してから使う。
> エラーは「どこで・何をして・何を期待して・何が起きたか・何回中何回出たか」をそろえる。翻訳オン／オフでも試す。
